Titelkontext

Was diese Bühne ist – und was nicht.

Diese Seite ist

  • eine transparente Anzeige für echte Titelmetadaten
  • ein lokaler Favoritenbereich ohne Account
  • eine Timeline für zuletzt gespielte Tracks

Diese Seite ist nicht

  • kein Ersatz für fehlende Datenquellen
  • kein Generator für erfundene Titel
  • kein versteckter Tracking-Feed

Endpoint /station/jackdarckart/last_songs

Die Historie wird live aus derselben offiziellen API geladen. Bei Nichterreichbarkeit wird der Grund erklärt und kein leerer Pseudozustand erzeugt.

    Noch keine Historie verfügbar. Sobald die offizielle API erreichbar ist, erscheinen hier zuletzt gespielte Titel.

    Was tun, wenn die Historie leer bleibt?
    • Nutze „Jetzt aktualisieren“, um die offiziellen API-Endpunkte erneut abzurufen.
    • Prüfe bei Problemen CORS oder einen optionalen Same-Origin-Proxy.
    • Auch ohne Historie bleibt die Wiedergabe uneingeschränkt nutzbar.
