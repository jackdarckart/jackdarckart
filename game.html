Subdomain-Destination · jackdarckart/game

Singularity Arcade: Quantum Vault als eigenständiges Game-Projekt.

Singularity Arcade (jackdarckart/game) ist als eigenständige Subdomain-Destination für stream-musik.space angebunden. Das Projekt verbindet ein interaktives Arcade-Game mit vollwertigem Account-System, serverseitig verschlüsseltem Quantum Vault und dediziertem Node.js-Backend.

Integration & Trennung

Warum Subdomain statt monolithischer Verschmelzung?

  • Kein Node.js auf GitHub Pages: Die Hauptseite ist ein statisches GitHub-Pages-Frontend ohne serverseitige Ausführung.
  • Sicherheitsgrenze für Accounts: Private Account-Sessions, Passworthashes und Vault-Dateien gehören nicht in das statische Radio-Repo.
  • Audio bleibt stabil: Das Spiel läuft in eigener Umgebung, während stream-musik.space als fokussierte Listening-Console aktiv bleibt.
  • Unabhängig versionierbar: Beide Repositories (jackdarckart/jackdarckart und jackdarckart/game) können eigenständig gewartet und deployt werden.
Architektur-Vergleich

Zwei Projekte, zwei Rollen, eine saubere Schnittstelle.

Um das Web-Radio schlank und zuverlässig zu halten, werden das Hauptportal und das Game getrennt betrieben.

Hauptseite · stream-musik.space

Statische Radio-Web-App (Repository jackdarckart/jackdarckart)

  • Gehostet auf GitHub Pages mit CNAME stream-musik.space
  • Reines Client-Side-HTML/CSS/JS ohne Build-Pipeline
  • Fokus auf Live-Stream, Titeldaten, PWA und Radio-Tools
  • Keine Datenbank, keine serverseitigen Sessions

Singularity Arcade · jackdarckart/game

Eigenständiges Node.js-Spiel (Repository jackdarckart/game)

  • Benötigt Node.js ≥ 20.6.0 (server/server.js)
  • HttpOnly-Cookie-Sessions und scrypt-Passworthashes
  • Verschlüsselter Quantum Vault mit AES-256-GCM auf dem Server
  • Canvas-Spielfeld, Mining, Resonanz und öffentliche Rangliste

Subdomain-Brücke · game.stream-musik.space

Ziel-Infrastruktur für produktiven Betrieb

  • DNS CNAME/A-Record von game.stream-musik.space auf Node-Host
  • Hosting z. B. via Render, Railway, Fly.io, VPS oder Docker
  • Gleichbleibende Nutzerführung unter der Domain stream-musik.space
  • Fallback auf lokalen Entwicklungs-Server unter http://127.0.0.1:3000

Spielfeatures im Überblick

Singularity Arcade Modules

Quantum Vault

Dein Spielstand liegt verschlüsselt auf dem Server. Kein Verlust durch Leeren des Browser-Caches, echter Gerätewechsel per Login möglich.

Singularity Core

Interaktives Canvas-Spielfeld mit Mining, Resonanz-Multiplikatoren und erweiterbaren Tree-Node-Upgrades.

Jukebox & Live-Radio

Das Spiel bindet den offiziellen jackdarckart-Stream als Soundtrack-Jukebox direkt in die Arcade ein.

Public Leaderboard

Öffentliche Rangliste mit Spieler-Handle und Vibe Score – private Vault-Inhalte bleiben geschützt.

Lokale Ausführung

Entwickler-Schnellstart

Um Singularity Arcade lokal auf deinem Rechner zu testen:

  1. Klonen: git clone https://github.com/jackdarckart/game.git
  2. Prüfen: npm run check im Game-Projektordner
  3. Starten: npm start (lauscht standardmäßig auf Port 3000)
  4. Spielen: Im Browser http://127.0.0.1:3000 aufrufen
